# 🌐 Friday Server & Web Client

Ядро экосистемы Friday — центральный сервер маршрутизации и современный веб-клиент для управления умными устройствами прямо из браузера.

---

## 🌟 Основные фичи сервера

### 🔄 Кросс-девайс маршрутизация (Smart Routing)
* ИИ автоматически определяет, с какого устройства поступил запрос, и ищет в сети подходящее устройство для его выполнения.
* *Пример:* Вы можете сказать в телефон с улицы: *"Закрой Chrome на моем ПК и отправь робота в спальню"*, и сервер сам распределит задачи между Windows-клиентом и Raspberry Pi.

### 🧠 Единый мозговой центр
* Сервер выступает в роли "Оркестратора", опрашивая клиентов через асинхронные WebSocket-соединения.
* Интеграция с официальными API Google: `gemini-3.5-flash-lite`, `gemini-3.5-flash` (Computer Use) и `gemini-robotics-er-2-preview`.

---

## 🖥️ Возможности Веб-интерфейса (Сайта)

Веб-клиент позволяет получить доступ к функционалу Friday без установки приложений.

### 🎙️ Продвинутое аудио-взаимодействие (AudioWorklet)
* Захват звука с микрофона прямо в браузере с использованием `AudioContext` и `AudioWorklet` для устранения задержек.
* Встроенный VAD (Voice Activity Detection) — браузер сам определяет, когда вы говорите, и отправляет аудио-чанки на сервер.
* Эхоподавление: автоматическая пауза слушания во время ответа ассистента.

### 🎥 Трансляция экрана и камеры из браузера
* Поддержка `getUserMedia` и `getDisplayMedia`.
* Вы можете "пошарить" свой экран или веб-камеру прямо на сайте, чтобы ИИ проанализировал открытые у вас вкладки или документы в реальном времени.

### 🔐 Безопасность и аккаунты
* JWT-аутентификация и сессионный доступ.
* Гостевые сессии с ограниченными правами.
* Иерархия устройств: возможность предоставлять доступ к своему ПК другим авторизованным пользователям в системе.
